# Intelligent Pesticide Sprinkling System

An AI and IoT based intelligent pesticide sprinkling system designed for precision agriculture. The system detects plant infection using a camera and AI, then adjusts pesticide spraying according to the infection severity.

## 🚜 Project Overview

Traditional pesticide spraying often applies the same amount of pesticide across the entire field without considering the actual infection level of plants. This can lead to pesticide wastage, increased farming costs, and environmental impact.

Our system uses **AI, Computer Vision, IoT, and automated spraying** to detect infection and control pesticide application according to the severity level.

## 💡 How It Works

**Camera → AI/ML Detection → Infection Severity → IoT Sprayer → Targeted Pesticide Spraying**

The system classifies infection severity into:

- 🟢 Low
- 🟡 Medium
- 🔴 High

The pesticide dosage is adjusted according to the detected infection level.
